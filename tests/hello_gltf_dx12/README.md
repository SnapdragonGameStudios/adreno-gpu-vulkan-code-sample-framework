# Hello glTF DirectX 12 test

Loads a glTF scene using the DirectX 12 framework components.

## Build and run

Follow the [framework configuration instructions](../../README.md#configuring), select `hello_gltf_dx12`, and build for Windows. Follow the [run instructions](../../README.md#running).

When creating a new target from this test, update its CMake project name and add its selection to `Config.txt`. Run Windows executables with the test directory as the working directory.
