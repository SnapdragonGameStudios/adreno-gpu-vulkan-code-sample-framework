# Hello glTF Vulkan test

Loads a glTF scene with camera movement and basic lighting. Use it as a starting point for a Vulkan application.

## Build and run

Follow the [framework configuration instructions](../../README.md#configuring), select `hello_gltf_vulkan`, and build for Windows and Android. Follow the [run instructions](../../README.md#running).

When creating a new target from this test, update its CMake project name and add its selection to `Config.txt`. Run Windows executables with the test directory as the working directory.
