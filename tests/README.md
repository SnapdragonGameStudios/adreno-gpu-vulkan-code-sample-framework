# Test applications

These applications exercise the framework and provide starting points for new targets. Follow the [build instructions](../README.md#configuring) and select the test in `Configure.py`.

| Test | Purpose | Platform |
|---|---|---|
| [empty](empty/README.md) | A minimal application linked to the framework. | Windows and Android |
| [framework_test_vulkan](framework_test_vulkan/README.md) | Loads a glTF model and texture and renders them with Vulkan. | Windows and Android |
| [hello_gltf_vulkan](hello_gltf_vulkan/README.md) | Loads a glTF scene with camera movement and basic lighting. Use it as a starting point for a Vulkan application. | Windows and Android |
| [framework_test_dx12](framework_test_dx12/README.md) | Loads a glTF model and texture and renders them with DirectX 12. | Windows |
| [hello_gltf_dx12](hello_gltf_dx12/README.md) | Loads a glTF scene using the DirectX 12 framework components. | Windows |
