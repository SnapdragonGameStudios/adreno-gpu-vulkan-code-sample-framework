# DirectX 12 framework test

Loads a glTF model and texture and renders them with DirectX 12.

## Build and run

Follow the [framework configuration instructions](../../README.md#configuring), select `framework_test_dx12`, and build for Windows. Follow the [run instructions](../../README.md#running).

When creating a new target from this test, update its CMake project name and add its selection to `Config.txt`. Run Windows executables with the test directory as the working directory.
