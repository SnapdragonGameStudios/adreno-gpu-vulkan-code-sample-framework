# Image processing bloom sample

Implements bloom using `VK_QCOM_image_processing`.

Set `gUseExtension` to `true` to use the extension in the downsample and blur passes. Set it to `false` to compare the standard path. The extension path requires device and driver support.

## Build and run

Follow the [framework setup](../../README.md#configuring), select `image_processing`, and build the target platform. Use the [run instructions](../../README.md#running) for installation, working directories, and configuration.
