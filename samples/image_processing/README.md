# VK_QCOM_Image_Processing Bloom Sample

This demonstrates how to use the *[VK_QCOM_image_processing](https://docs.vulkan.org/refpages/latest/refpages/source/VK_QCOM_image_processing.html)* extension in a simple bloom shader.
Setting gUseExtension to false will use a standard method, setting to true will use the extension in the downsample and blur passes.
